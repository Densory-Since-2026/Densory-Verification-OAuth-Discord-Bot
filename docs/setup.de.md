# Densory Verify — Einrichtung

## Voraussetzungen

- Eigene Discord-Application (Client ID, Secret, Bot-Token)
- Verifiziert-Rolle auf deinem Ziel-Server
- Bot mit Berechtigung „Nachrichten senden" und „Embed Links"

## Einrichtungs-Schritte

1. **Discord-App verbinden**
   Hinterlege deine App-Daten im Dashboard — integrierte Health-Checks führen dich sicher durchs Setup.
2. **Dein Branding**
   Wähle Slug, Farben und Verify-Page-Design — es wirkt wie dein Server, nicht wie ein Fremd-Tool.
3. **Schutz aktivieren**
   Stelle Captcha, Account-Alter und Blocklists nach Bedarf ein — von entspannt bis streng.
4. **Panel live schalten**
   Poste das Verify-Panel in deinen Discord — Mitglieder klicken, verifizieren sich per OAuth, fertig.
